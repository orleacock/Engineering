## 1. Directory & Containment Architecture

## 2. Multi-Customer / Peer-Entity Isolation Law

- Every project dossier in `Projects/<Project>/<Project>.md` declares an explicit `entity:` and `compartment:` in YAML frontmatter.
- **Zero Cross-Entity Contamination**: When working on a project owned by `entity: Client_A`, the AI assistant and scripts must **never** link to, read, cite, or borrow specifications from any `Projects/<Other>/` or `Tasks/<Other>_Tasks.md` owned by `entity: Client_B` unless explicitly authorized by the user in the active turn.

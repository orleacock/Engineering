## 2. Rejected & Avoided Approaches (`v0.3.5`)

1. **Pulling `verified_fastpath.py` into Clean-Room `Homunculus/` (Rejected)**: Kept strictly in `Engineering/scripts/` (`compartment: private`) with zero `/home/orin`, `orleacock`, or `verified_fastpath` tokens inside `Homunculus/` (`cleanroom`), keeping parent workflow acceleration isolated from clean-room releases and downstream project repos.
2. **Caching `audit_data_boundary.py --staged` (Rejected)**: Violates `#3 Data Safety`; staged diffs and credential/encoding checks execute live on every pre-commit invocation.
3. **Python `pickle` Cache for `SourceIndex` (Rejected)**: Replaced with pure-JSON (`json.loads`/`json.dumps`) schema serialization + SHA-256 verification to avoid unsafe deserialization primitives.
4. **Top-Level `<memory_root>/Quarantine/` Directory (Rejected)**: Breaks `Alchemical-3D` / `NetCom` / `Orin_Workstation` cross-entity partitioning; replaced by `Projects/<Project>/Quarantine/` + `TOP_LEVEL_QUARANTINE_FORBIDDEN`.
5. **Mid-Release Hotfix of Unleased `scripts/homunculus_paths.py#L1340-L1345` (Rejected for `v0.3.5`)**: Discovered during non-`bwrap` Tier-2/3 fallback (`SBX-20261114_160059-f59fbd69`); deferred as tracked `[ISOLATED]` follow-up `[OPEN-01]` in `Alchemical-3D_Tasks.md` rather than re-opening an additional `/dev/tty` Ring-0 lease mid-release.

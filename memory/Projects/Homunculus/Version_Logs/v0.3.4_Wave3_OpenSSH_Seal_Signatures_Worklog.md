## 2. Rejected & Avoided Approaches (`v0.3.4`)

1. **Linux-Only `chattr +i` Immutable Attributes (`C3` — Rejected)**: Breaks cross-OS (`macOS`/`Windows`) portability and requires root privileges during clean-room verification.
2. **Reading Private SSH Keys in Python (Rejected)**: Violates `data-and-credential-safety.md` §1; `homunculus_paths.py` validates `.pub` files and delegates signing strictly to `ssh-keygen -Y sign -f <pub>` via `SSH_AUTH_SOCK`.
3. **Mandatory Default `ssh-keygen` Signing on Fresh Clones (Rejected)**: Default `seal_signing: "off"` preserves `<1 ms` zero-dependency verification in CI and `bwrap --tmpfs $HOME` sandboxes.
4. **Inline-Only Signature Storage (Rejected)**: Default `local_config` (`~/.config/homunculus/seal_signatures.json`) keeps workstation SSH key/signature metadata out of clean-room git history while still supporting `inline` for self-contained bundles.

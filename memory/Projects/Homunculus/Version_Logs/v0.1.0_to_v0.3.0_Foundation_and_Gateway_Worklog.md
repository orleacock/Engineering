## 2. Rejected, Superseded & Failed Approaches (`v0.1.0` – `v0.3.0`)

Retained permanently per `W-1` so future sprints never re-introduce failed designs:

1. **Middle `Agent.md` Router Tier & Extra Relay Subagent (`LL-027`, `VRF-9558a2136173`)**:
   - *Why Rejected*: Split `always_on` governance across two sources of truth, burned an extra subagent turn, created Linux case-sensitivity hazards (`Agent.md` vs. `AGENTS.md`), and risked crossing Antigravity's `24,000 B` hard truncation cliff. Replaced by the 2-Tier Single-Source Rule Diet (`AGENTS.md <= 22,500 B`).
2. **Per-Edit `PostToolUse` Hooks & Mid-Task `--sync-visuals` (`LL-001`, `LL-002`)**:
   - *Why Rejected*: Re-rendering `.svg`/`.png` diagrams or running full audits after every single edit burned turns and invalidated prompt caches. Locked `hooks.json` `{}` + batched `pre-commit-gate` (`X -> Y -> Z`).
3. **Speculative B-Rep CAD Intent Heuristics (`LL-021`, `LL-031`)**:
   - *Why Rejected*: `classify_bore_diameter`, `.F. bore` vs. `.T. boss` guesses, and unmeasured `solid_abs_g` mass estimates turned raw `.step`/`.stl` geometry into hallucinated COTS fasteners inside `verify_claims.py`. Replaced by outer envelopes, closed `360°` circular surface counts (`not has_line`), and `[CAD STOP GATE]`.
4. **`--allow-lessons-source` Truth-Oracle Bypass (`Compare-Full`, `LL-040`)**:
   - *Why Rejected*: Permitting `verify_claims.py` to ingest `*_Lessons_Learned.md` created a self-referential circular grounding loophole where narrative prose validated new drafts. Deleted permanently.
5. **`.cache/memory_index.sqlite` Binary Search Store (`Stateful Memory Rebuild`, `LL-042`)**:
   - *Why Rejected*: SQLite WAL/file locks corrupt inside SharePoint/OneDrive/Dropbox-synced `Path A Headless` corporate directories. Replaced by tracked lightweight `<Entity>_memory_index.json` + gitignored `.cache/<Entity>_scoring_vectors.json`.
6. **`Mem0`-Style Unverified LLM Auto-Writes & Hard TTL Eviction (`Mem0` Review)**:
   - *Why Rejected*: LLM summarization on every write silently drifts numbers/constraints and TTL eviction erases critical `Chesterton's Fence` invariants. Retained deterministic `MEMORY_SDK_V1` reads/writes + non-destructive `TIER3`–`TIER5` archival (`Archive/`).
7. **`v0.2.1` 59-Probe Retrieval Dead-Ends (`LL-044`)**:
   - *Why Rejected*: (a) Unconditional `TIER0[:2]` insertion cannibalized `Top-K` slots on unrelated queries; (b) enforcing a `0.30 * max_dw` word-trigram floor broke multi-word natural queries; (c) tightening implicit sibling stem coverage to `>= 0.35` dropped valid secondary sibling hits; (d) counting 1-line Quick-Lookup rows toward `HOT_MEMORY_BLOAT_CEILING` caused false bloat blocks.
8. **Eager Memory Template Ejection (`LL-046`)**:
   - *Why Rejected*: Copying all `templates/memory/*.md` and `Templates/` subdirectories on every `--init-memory` created dozens of drifting static copies. Replaced by sparse `--eject-templates` + runtime resolution inside `Homunculus/templates/`.
9. **`v0.3.0` Prompt-Only Core Protection & `os.isatty()`-Only Auth (`LL-047`, `SBX-20261111_193742-8138292b`)**:
   - *Why Rejected*: Rule prompts alone could not stop subagent workspace mutations (`Ring 0` needed `0444` + `kernel_seal.json`), and `os.isatty()` alone returned `True` inside PTY-allocated AI agent harnesses. Replaced with live `/dev/tty` 4-char hex challenge + timeout.

## 2. Rejected & Avoided Approaches (`v0.3.3`)

1. **Stateful `telemetry_pulse_history.jsonl` Inside Clean-Room `Homunculus/` (Rejected — `Option A` Selected)**: Clean-room diagnostic probes must remain zero-write (`zero_host_writes: true`); rolling JSONL trend logging belongs strictly out-of-tree in `Engineering/scripts/benchmark_homunculus.py`.
2. **Naive Shared `setUpClass` Memory-Vault Fixtures Across `unittest` Methods (Rejected)**: Mutating shared temporary vault fixtures risks inter-test state poisoning; isolated per-file subprocesses with dedicated `TMPDIR` keep runs hermetic and fast.
3. **Blanket `rg` Replacement in `audit_data_boundary.py` (Rejected)**: `rg` alone cannot evaluate SHA-256 hash tokens, `UTF-16`/`UTF-32` streams cleanly in all modes, or `.xlsx`/`.docx`/`.3mf` ZIP XML parts; kept full Python scanning on all non-plain-UTF-8 paths.

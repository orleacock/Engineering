### `LL-019` [TIER3] — Standalone Zero-Vault / Zero-History Doctrine & Dynamic New-Project Discovery (Closing Hardcoded Project-List Cracks)
- **Symptom / Trap:** Auditing how `Homunculus` behaves when deployed standalone without a pre-existing `<memory_root>/` vault or when a **brand-new project** is onboarded exposed four structural cracks whenever scripts rely on hardcoded project lists:
  1. **`CROSS_ENTITY_CONTAMINATION` Disabled on New Projects (`verify_claims.py`):** Checking only a hardcoded project tuple when `project:` frontmatter was absent (which is true for `BOM.md`, `Assembly_Guide.md`, `README.md`, `.cfg`, and `.py` files) fell through to `return "*"` (wildcard global entity), allowing any brand-new project (`Project_Alpha`, `Project_Beta`) to bypass cross-entity contamination blocking!
  2. **Hardcoded CAD Stem Stripping & Vault-Required Crash (`inspect_hardware_ecosystem.py`):** Hardcoding assembly stem prefixes caused new CAD projects exported from Onshape/Fusion as `<NewAssembly_V1> - <PartName>.step` to fail to match `<PartName>.stl`, and running `inspect_hardware_ecosystem.py` without `<memory_root>/` crashed with `No matching project found`.
  3. **Hardcoded Task Umbrellas & Missing Bootstrapper (`sync_memory.py`):** Hardcoding `--tasks --umbrella` choices ignored newly created `Tasks/*.md` files and lacked an `--init-memory` / `--init-project` command to scaffold new projects deterministically.
  4. **Turn-1 Unindexed-Project Gap (`co-engineering-partner.md`):** Turn-1 routing assumed `Projects/<Project>/<Project>.md` already existed without defining the **New / Unindexed Project Gate** or **Standalone Zero-Vault Mode**.
- **Hardened Solution (`Accuracy & Truth > Efficiency > Speed`):**
  1. **Dynamic Entity Discovery in `verify_claims.py`:** Upgraded `_detect_entity()` to derive project entities dynamically from `Projects/<ProjectFolder>/`, enclosing `.git` repository roots, `Project_<Name>` / `<Name>_Hardware.md` naming, and `project:`/`parent_note:` frontmatter (`_canonicalize_entity_token`), and passed `idx_known_entities` into `detect_entities_in_text(ln, idx_known_entities)`.
  2. **Generic CAD Stem Matching & `--repo` Standalone Mode in `inspect_hardware_ecosystem.py`:** Generalized `STEM_PREFIX_RE` to strip any `<Assembly> - <Part>` prefix across all projects, added `--repo` standalone fallback when `<memory_root>/` is absent, and gated `os.makedirs` strictly behind `--sync-manifest`.
  3. **Dynamic Umbrella Discovery & `--init-memory` / `--init-project` in `sync_memory.py`:** Replaced hardcoded umbrella maps with dynamic `Tasks/*.md` discovery and added `--init-memory` + `--init-project <Name> --repo-path <Path>`.
  4. **3-Branch Turn-1 Routing in `co-engineering-partner.md`:** Codified (1) Indexed Project (`AUTO-TREE`), (2) New/Unindexed Project Gate (`--init-project` + live `--repo` inspection), and (3) Standalone Zero-Vault Mode.

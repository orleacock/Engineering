## 3. In-Script Developer & AI Navigation Map Standard (`=== DEVELOPER & AI NAVIGATION MAP ===`)

Every Python, Bash, and PowerShell script in `Homunculus/` embeds a standardized, zero-runtime-overhead navigation header inside its top module docstring or comment block (`StartLine=1, EndLine=50`) containing:
1. **`Owning Module`**: The governing skill or framework layer.
2. **`Callers` & `Callees`**: Direct internal imports, subprocess targets, and test suites.
3. **`CLI Flags`**: All supported `argparse` / shell flags.
4. **`Symbol Index`**: Two-pass AST-verified `#Lstart-Lend` line numbers for every top-level `class` and `def` so AI agents and developers can read `StartLine=1, EndLine=50` and jump directly to the exact `30–80` line target window in a single turn without `grep` or multi-chunk full-file reads.

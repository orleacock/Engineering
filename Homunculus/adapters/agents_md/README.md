# Universal `AGENTS.md` Adapter (`adapters/agents_md/`)

Governed by: **`1. Accuracy & Truth -> 2. Efficiency -> 3. Data Safety -> 4. Speed`**

## Zero-Install Drop-In Usage
Copy [`AGENTS.md`](AGENTS.md) to the root of your project repository (or run `python3 Homunculus/scripts/build_adapters.py --workspace /path/to/project --client agents_md`). Any `AGENTS.md`-compatible harness (OpenAI Codex, Windsurf, Aider, Zed, etc.) will automatically load all 3 Homunculus core rules and the on-demand skill index.

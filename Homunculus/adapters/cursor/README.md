# Cursor IDE Adapter (`adapters/cursor/`)

Governed by: **`1. Accuracy & Truth -> 2. Efficiency -> 3. Data Safety -> 4. Speed`**

## Zero-Install Drop-In Usage
Copy `adapters/cursor/rules/*.mdc` into your project's `.cursor/rules/` directory and copy `templates/ignore/.cursorignore` to your project root (or run `python3 Homunculus/scripts/build_adapters.py --workspace /path/to/project --client cursor`).

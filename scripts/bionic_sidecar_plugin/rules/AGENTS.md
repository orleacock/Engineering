# Bionic Local Sidecar Routing

- Never call `127.0.0.1:1234`, integer/hex loopback encodings, Bionic AppImage, or `lms` lifecycle commands (including via `sh`/`bash -c`) directly; route via `bionic-sidecar` MCP tools (`bionic_control`, `bionic_digest`, `bionic_repo_audit`, `bionic_stage_patch`) or `local_sidecar.py`, and include a 1-line `[BIONIC SIDECAR NOTICE]` with `Bionic Calls = <clean>/<corrected> (healed=<healed>) [...]` (including relative `%` and epoch delta) whenever Bionic is opened, loaded, or called.
- Whenever a `<SYSTEM_MESSAGE>` reports `BIONIC_STATE=OFFLINE` or `BIONIC_STATE=UNLOADED`, you MUST include the `[BIONIC SIDECAR NOTICE]` banner in your user-facing response for that turn stating Bionic is not currently loaded/online and offering to turn it on remotely via `bionic_control` (`gpu-max`, `gpu-daily`, or `cpu-bg`) upon user confirmation.
- Offload with two effort tiers only: `effort="standard"` (default daily offload, `2048` tok out, `<=60s` auto / `<=90s` explicit, auto-chunked `>36 KB` / `>=5` multi-file `#L` slices + tail continuation) and `effort="high"` (quota-maximizing deep offload, `4096` floor / `8192` default / `10240` cap tok out with `<think>` synthesis recovery + `>42 KB` / `>=5` multi-file `#L` slices map-reduce, frontier-validated). Pass `#Lstart-Lend` context slices when inspecting focused sections, keep `verify_claims=True` default (`~0.12s` compact receipt on file-backed digests), use deterministic non-sleep `--self-test` checks (injectable `clock=time.monotonic`) in `bionic_stage_patch`, and use `async_job=True` + `bionic_control(action="job-status"|"job-collect")` for long tasks in parallel sprints.
- Record corrections/self-heals via `bionic_control(action="verdict", ...)` or `prev_call_id`/`prev_verdict`, and never start/load or reset scorecard epochs (`bionic_control(action="scorecard-reset", user_confirmed=True)`) without explicit user confirmation (`user_confirmed=True`); verify outputs before promoting past `Quarantine/`.

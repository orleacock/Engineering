# Apprentice Multi-Backend Sidecar Routing

- Never call `127.0.0.1:1234`, integer/hex loopback encodings, Bionic AppImage, or `lms` lifecycle commands directly; route local offloads via `apprentice` MCP tools (`apprentice_control`, `apprentice_digest`, `apprentice_repo_audit`, `apprentice_stage_patch`, `apprentice_shadow_review`) or `apprentice_engine.py`, and include a 1-line `[APPRENTICE NOTICE]` with `Apprentice Calls = <clean>/<corrected> (healed=<healed>) [...]` whenever Apprentice is opened, loaded, or called.
- Whenever a `<SYSTEM_MESSAGE>` reports `OFFLINE` or `UNLOADED`, include the `[APPRENTICE NOTICE]` banner in your user-facing response offering to load/start the active backend remotely via `apprentice_control` (`gpu-max`, `gpu-daily`, or `cpu-bg`) upon user confirmation.
- **Host-Tier Postures (`1. Accuracy & Truth > 2. Efficiency -> 3. Data Safety > 4. Speed`)**:
  - **`EXECUTION_TIER` (`Hydrogen` / `Sonnet` — Speed-First)**: Keep `<25KB` reads, `30–80` line code windows, and small helpers native on the host model; offload `>=25KB` (`>=4`-doc) reconciliations/audits (`apprentice_digest` / `apprentice_repo_audit`) and run `apprentice_shadow_review(async_job=True, include_git_diff=True)` at `pre-commit-gate` on multi-file/spec/firmware commits.
  - **`FRONTIER_TIER` (`Carbon` / `Neon` / `Opus` — Accuracy-Locked Quota-Shield)**: Never replace Frontier direct reads on load-bearing code, `Ring 0`, or primary specs (`30–80` line windows stay native); offload **(1)** `>=8KB` test/sandbox log coordinate sieves (via `apprentice_digest` + mandatory `Gate 3` direct `read_file` on flagged `#L` hunks), **(2)** `#L`-anchored `Version_Logs/` candidate harvesting, **(3)** `>=3KB` disposable `scratch/*.py` fixtures via `apprentice_stage_patch` (verified by execution), and **(4)** additive `pre-commit-gate` `apprentice_shadow_review(async_job=True, include_git_diff=True)`.
- Offload with `effort="auto"` as default (runs `STANDARD` for single-file/extract/`stage_patch` calls `<=2` concurrent `async_job=True`; auto-escalates cross-file contradiction audits to Single-Shot `HIGH` `<=54KB` or Lossless Map=`STANDARD` -> Reduce=`HIGH` `8192`-cap `>54KB`). Keep `verify_claims=True` default (supports `include_git_diff` via `.patch` mount), and collect async jobs with `apprentice_control(action="job-collect-any"|"job-collect", job_ids=[...], wait_seconds=120)`.
- Only call `apprentice_control(action="verdict", ...)` or `prev_call_id`/`prev_verdict` when overriding an auto-recorded `clean`/`healed` verdict (e.g., marking `corrected` after `Gate 3`); never reset epochs (`scorecard-reset`) without `user_confirmed=True`, and verify drafts before promoting past `Quarantine/`.
